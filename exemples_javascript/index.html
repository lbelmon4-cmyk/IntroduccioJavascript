Exemples de JavaScript · RA3

Cada exemple és una pàgina petita amb el seu fitxer .js comentat. Obre'l amb VS Code, llegeix-lo, executa'l al navegador i fes les proves que es proposen al final de cada fitxer. Els exemples segueixen l'ordre de la presentació de teoria.

Introducció, variables i tipus de dades

  • 01 · El primer script
    Tres maneres d'incloure JavaScript a l'HTML, comentaris, majúscules i minúscules, i el primer canvi al DOM.
  • 02 · Variables: var, let i const
    Diferències d'àmbit entre var i let, const que no es pot tornar a assignar però sí modificar si és un array o un objecte, i identificadors vàlids.
  • 03 · Hoisting
    Què passa quan fem servir una variable o una funció abans de declarar-la.
  • 04 · Tipus de dades
    typeof, undefined contra null, i la diferència entre copiar un valor primitiu i copiar la referència d'un objecte.

Operadors i funcions

  • 05 · Operadors == i ===
    Una taula amb comparacions que donen resultats diferents segons l'operador. Observa-la bé: sovint sorprèn!
  • 06 · Funcions, arrow functions i callbacks
    Les tres maneres d'escriure una funció i els callbacks amb bucles, esdeveniments i temporitzadors.

El DOM i els esdeveniments

  • 07 · Seleccionar elements del DOM
    Els quatre mètodes de selecció i què retorna cadascun. Els botons ressalten el que ha seleccionat cada mètode.
  • 08 · Crear, afegir i eliminar elements
    Una llista de tasques que es construeix amb createElement i appendChild, i es redueix amb remove(). També la diferència entre textContent i innerHTML.
  • 10 · Llegir camps i reaccionar en directe
    L'esdeveniment input per fer un comptador de caràcters en directe, i com llegir el valor d'un select, d'una casella i d'un camp numèric.

Estils

  • 09 · Manipular estils: style i classList
    Dues maneres de canviar l'aspecte d'un element: la propietat style (regla a regla) i classList (afegir i treure classes).
  • 14 · Mode fosc
    Un botó que alterna entre mode clar i fosc afegint o traient una classe al body amb classList.toggle().

Per entendre com es construirà la pràctica

  • 11 · Array d'objectes i targetes amb un bucle
    Les dades viuen en un array d'objectes i JavaScript crea les targetes amb un bucle. Observa que el contenidor de l'HTML és buit.
  • 12 · Cerca i filtre en directe
    Escriu per cercar i tria una comarca per filtrar: cada canvi filtra l'array amb un callback i torna a pintar la llista.
  • 13 · Validar un formulari
    Un formulari amb novalidate, validació amb JavaScript, missatges d'error creats amb el DOM, i un resum de confirmació en enviar-lo correctament.

Recorda: els exemples 11, 12 i 13 fan servir altres temes (llibres, ciutats, club de lectura) perquè aprenguis la tècnica; a la pràctica l'hauràs d'aplicar tu a la botiga de videojocs.
